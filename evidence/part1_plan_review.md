## Kết luận review

Plan dùng đúng Order API identity/response hiện có và nhận ra worker/client còn thiếu, nhưng các điểm sau phải được giữ rõ trước khi code:

1. **Claim Saga step chưa tồn tại:** schema fields và finder không tạo quyền sở hữu. Cần thiết kế atomic claim/token ownership; không coi finder là claim.
2. **Không lặp test idempotency đã có:** replay, conflict, scope và cạnh tranh tạo cùng key đều có coverage; chỉ thêm tests về hành vi nền chưa được cover.
3. **Không mặc định polling/broker:** cần quyết định runtime/deployment/worker lifecycle trước khi chọn cơ chế.
4. **Tiến trình user nhìn thấy chưa được định nghĩa:** API hiện chỉ trả Order status. Cần xác nhận Order-level status đủ hay cần status theo Saga step; không thêm `progress`, ETA hay `taskId` theo suy đoán.
5. **Outbox write đã có, publisher chưa có:** reuse transaction state + Outbox; đưa broker/consumer/dedup vào scope chỉ khi change request yêu cầu.

Plan chưa được thực thi. Không có test, production code, migration, README hoặc requirements nào được sửa trong Phần 1.
